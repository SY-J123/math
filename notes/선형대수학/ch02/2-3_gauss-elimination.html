2.3가우스 소거법 Gauss elimination

행제형 행렬의 개념이 주어졌으므로, 이것을 이용해 가우스 소거법(Gauss elimination)을 정리해 보자.

알고리즘 2.1가우스 소거법

일차연립방정식 $AX=B$ 를 푸는 절차는 다음과 같다.

  1. 단계 1. 행렬 $A$ 와 $B$ 로부터 확대행렬 $C=(A\mid B)$ 를 구성한다.
  2. 단계 2. 기본행연산을 적용하여 $C$ 를 행제형으로 변환한다.
  3. 단계 3. 후진대입법을 이용하여 해를 구한다.
여기서 $AX=B$ 는 행렬방정식의 형태이다. 행렬의 곱을 배우는 제3장에서 쉽게 이해할 수 있다. $A$, $B$ 는 일차연립방정식의 계수행렬과 상수행렬이고, $X$ 는 미지수 행렬이다.

선도변수와 자유변수 leading & free variables

정의선도변수와 자유변수

[알고리즘 2.1]의 단계 2에서 얻은 행제형 행렬에서

  1. 선도원소가 속한 열에 대응하는 미지수를 선도변수(leading variable)라 한다.
  2. 이 외의 미지수를 자유변수(free variable)라 한다.
예제 2.8확대행렬과 선도변수·자유변수의 판별

다음 일차연립방정식의 확대행렬을 구하라.

$$\begin{cases} v+3w\ \ \ \ \ \ \ -3y\ \ \ \ \ \ \ =3\\ \ \ \ \ \ \ w-2x+2y-2z=5\\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ y+\ \ z=4 \end{cases}$$

풀이  미지수를 $v,w,x,y,z$ 의 순서로 두면 확대행렬은 다음 행렬 $A$ 와 같다.

$$A=\left(\begin{array}{ccccc|c} 1&3&0&-3&0&3\\ 0&1&-2&2&-2&5\\ 0&0&0&1&1&4 \end{array}\right)$$

행렬 $A$ 는 행제형이며, 선도원소는 $1$열·$2$열·$4$열에 있다. 따라서 미지수 $v,w,y$ 는 선도변수이고 $x,z$ 는 자유변수이다.

후진대입 back substitution

해가 존재하는 일차연립방정식의 확대행렬이 행제형으로 변환된 후에는 다음 절차에 따라 해를 구한다. [알고리즘 2.2]는 [알고리즘 2.1]의 단계 3에서 사용하는 후진대입을 나타낸 것이다.

알고리즘 2.2후진대입
  1. 단계 1. 각각의 자유변수를 임의의 매개변수로 둔다.
  2. 단계 2. 영행이 아닌 행 중에서 가장 아래에 있는 행을 찾고, 그 위치를 $i$번째로 한다.
  3. 단계 3. $i$번째 행을 그 행의 선도변수에 관해 푼다.
  4. 단계 4. $i=1$ 이면 종료하고, $i>1$ 이면 $i\leftarrow i-1$ 로 $i$ 값을 변경한 다음 단계 3을 수행한다.
예제 2.9자유변수가 있는 경우의 후진대입

[예제 2.8]의 연립방정식에 대한 확대행렬 $A$ 는 행제형이다. [알고리즘 2.2]를 수행하여 해를 구하라.

풀이

단계 1에서 자유변수인 $x$ 와 $z$ 를 각각 $x=s$, $z=t$ 와 같이 매개변수로 둔다. 단계 2에서 $i=3$ 임을 알 수 있다. 단계 3에서 $i=3$ 인 행의 선도변수는 $y$ 이므로 $y+z=4$ 를 풀면 $y=-t+4$ 이다.

단계 4에서 $i\leftarrow i-1=3-1=2$ 를 두고 단계 3으로 간다. 단계 3에서 $i=2$ 인 행의 선도변수 $w$ 에 대해 풀면 다음과 같다.

$$\begin{aligned} w&=5+2x-2y+2z\\ &=5+2s-2(-t+4)+2t\\ &=2s+4t-3 \end{aligned}$$

다시 단계 4에서 $i=1$ 로 두고 단계 3으로 간다. 단계 3에서 $i=1$ 인 행의 선도변수 $v$ 에 대해 풀면 다음과 같다.

$$\begin{aligned} v&=3-3w+3y\\ &=3-3(2s+4t-3)+3(-t+4)\\ &=-6s-15t+24 \end{aligned}$$

이제 단계 4에서 종료조건 $i=1$ 을 만족하므로 종료된다. 결국 이 연립방정식의 해는 다음과 같이 무수히 많다.

$$v=-6s-15t+24,\quad w=2s+4t-3,\quad x=s,\quad y=-t+4,\quad z=t$$

예를 들어 매개변수 $s=0$, $t=1$ 로 놓으면 $v=9$, $w=1$, $x=0$, $y=3$, $z=1$ 이 하나의 해가 된다.

[예제 2.8]의 연립방정식처럼 방정식의 개수($3$개)가 미지수의 개수($5$개)보다 적은 연립방정식을 부정방정식이라고 한다. 부정방정식은 무수히 많은 해를 갖는다. 다만 이는 해가 존재하는 경우에 대한 이야기다 — 방정식 수가 적더라도 $0=1$ 꼴의 모순된 행이 나오면 해가 아예 없을 수 있다.

유일한 해를 갖는 경우 the unique-solution case

예제 2.10행렬방정식으로 나타내고 행제형으로 변환

다음 일차연립방정식을 행렬방정식으로 나타내고, 기본행연산을 적용하여 확대행렬을 행제형 행렬로 변환하라.

$$\begin{cases}2x-3y+2z=-3\\ \ \ x-2y\ \ \ \ \ \ \ =\ \ \ 4\\ \ \ \ \ \ \ \ \ y-\ \ z=\ \ \ 1\end{cases}$$

풀이  행렬방정식 $AX=B$ 는 다음과 같다.

$$\begin{pmatrix}2&-3&2\\1&-2&0\\0&1&-1\end{pmatrix} \begin{pmatrix}x\\y\\z\end{pmatrix}=\begin{pmatrix}-3\\4\\1\end{pmatrix}$$

기본행연산을 적용하기 위하여 확대행렬로 나타내면 다음 행렬 $C$ 와 같다.

$$C=\left(\begin{array}{ccc|c}2&-3&2&-3\\1&-2&0&4\\0&1&-1&1\end{array}\right)$$

이제 행렬 $C$ 에 기본행연산을 차례대로 적용하여 행제형으로 변환한다.

$$\begin{aligned} &\left(\begin{array}{ccc|c}2&-3&2&-3\\1&-2&0&4\\0&1&-1&1\end{array}\right) \xrightarrow{\ R_{1,2}\ } \left(\begin{array}{ccc|c}1&-2&0&4\\2&-3&2&-3\\0&1&-1&1\end{array}\right)\\[8pt] &\xrightarrow{\ R_{1,2}(-2)\ } \left(\begin{array}{ccc|c}1&-2&0&4\\0&1&2&-11\\0&1&-1&1\end{array}\right) \xrightarrow{\ R_{2,3}(-1)\ } \left(\begin{array}{ccc|c}1&-2&0&4\\0&1&2&-11\\0&0&-3&12\end{array}\right)\\[8pt] &\xrightarrow{\ R_3\left(-\frac13\right)\ } \left(\begin{array}{ccc|c}1&-2&0&4\\0&1&2&-11\\0&0&1&-4\end{array}\right) \end{aligned}$$

행제형으로 변환된 마지막 확대행렬에 후진대입법을 적용해 보자. 이 경우는 자유변수가 없으며, $i=3$ 인 행이 가장 아래의 영행이 아닌 행이다.

  1. $i=3$ : 선도변수 $z$ 에 대해 풀어 $z=-4$ 를 얻는다.
  2. $i=2$ : $y=-11-2z=-11+8=-3$.
  3. $i=1$ : $x=4+2y=4-6=-2$.

따라서 이 일차연립방정식은 유일한 해 $x=-2$, $y=-3$, $z=-4$ 를 갖는다.

선도변수의 개수가 미지수의 개수와 같으면 자유변수가 없으므로 해가 유일하고, 자유변수가 하나라도 있으면 매개변수만큼 해가 무수히 많아진다. 즉 1.2절에서 본 유일·부정의 갈림이 행제형에서는 선도원소를 몇 개 만들 수 있는가의 문제로 바뀐다.
