2.4가우스–조르단 소거법 Gauss–Jordan elimination

가우스 소거법은 일차연립방정식의 해법에서 확대행렬을 행제형으로 변환한 후 후진대입법을 이용하여 해를 구한다. 이 절에서 설명하는 가우스–조르단 소거법(Gauss–Jordan elimination)은 후진대입을 사용하지 않는다는 점에서 다르다. 반면에 확대행렬을 소거행제형으로 변환해야 하는 부담이 있다.

알고리즘 2.3가우스–조르단 소거법

일차연립방정식 $AX=B$ 를 푸는 절차는 다음과 같다.

  1. 단계 1. 계수행렬 $A$ 와 상수행렬 $B$ 로부터 확대행렬 $C=(A\mid B)$ 를 구한다.
  2. 단계 2. 기본행연산을 이용하여 $C$ 를 소거행제형 행렬 $D$ 로 변환한다.
  3. 단계 3. 자유변수 각각을 임의의 매개변수로 둔다.
  4. 단계 4. 행렬 $D$ 의 $0$ 이 아닌 각 행을 선도변수에 대해 푼다.
가우스–조르단 소거법은 행렬을 소거행제형으로 변환하는 과정이 핵심이다. 이것은 행렬을 먼저 행제형으로 변환한 다음, 각 선도원소가 속한 열의 나머지 원소 (즉 선도원소의 위쪽 원소들)를 모두 $0$ 으로 만들면 된다.

유일한 해를 갖는 경우 unique solution

예제 2.11[예제 2.10]을 가우스–조르단으로 다시 풀기

다음 연립방정식을 가우스–조르단 소거법으로 풀어라.

$$\begin{cases}2x-3y+2z=-3\\ \ \ x-2y\ \ \ \ \ \ \ =\ \ \ 4\\ \ \ \ \ \ \ \ \ y-\ \ z=\ \ \ 1\end{cases}$$

풀이  확대행렬 $A$ 와 이를 행제형으로 변환한 행렬 $B$ 는 다음과 같다(변환 과정은 [예제 2.10]과 같다).

$$A=\left(\begin{array}{ccc|c}2&-3&2&-3\\1&-2&0&4\\0&1&-1&1\end{array}\right),\qquad B=\left(\begin{array}{ccc|c}1&-2&0&4\\0&1&2&-11\\0&0&1&-4\end{array}\right)$$

이제 행렬 $B$ 에 기본행연산을 적용하여 소거행제형으로 변환해 보자.

$$\begin{aligned} &\left(\begin{array}{ccc|c}1&-2&0&4\\0&1&2&-11\\0&0&1&-4\end{array}\right) \xrightarrow{\ R_{2,1}(2)\ } \left(\begin{array}{ccc|c}1&0&4&-18\\0&1&2&-11\\0&0&1&-4\end{array}\right)\\[8pt] &\xrightarrow{\ R_{3,1}(-4)\ } \left(\begin{array}{ccc|c}1&0&0&-2\\0&1&2&-11\\0&0&1&-4\end{array}\right) \xrightarrow{\ R_{3,2}(-2)\ } \left(\begin{array}{ccc|c}1&0&0&-2\\0&1&0&-3\\0&0&1&-4\end{array}\right) \end{aligned}$$

마지막 소거행제형 행렬에 대응하는 방정식은 다음과 같다.

$$\begin{cases}x\ \ \ \ \ \ \ \ \ \ \ =-2\\ \ \ \ \ y\ \ \ \ \ \ =-3\\ \ \ \ \ \ \ \ \ z=-4\end{cases}$$

따라서 연립방정식의 해가 $x=-2$, $y=-3$, $z=-4$ 임을 바로 알 수 있고, 이 해는 [예제 2.10]에서 구한 해와 같다.

해가 무수히 많은 경우 infinitely many solutions

예제 2.12자유변수가 둘인 연립방정식

다음 연립방정식을 가우스–조르단 소거법으로 풀어라.

$$\begin{cases} p+2q+3r-4s=5\\ p+3q+3r+3s=3\\ \ \ \ -q\ \ \ \ \ \ \ -7s=2 \end{cases}$$

풀이  확대행렬을 구하면 다음 행렬 $A$ 와 같다.

$$A=\left(\begin{array}{cccc|c}1&2&3&-4&5\\1&3&3&3&3\\0&-1&0&-7&2\end{array}\right)$$

이제 행렬 $A$ 에 기본행연산을 적용하여 소거행제형으로 변환해 보자.

$$\begin{aligned} &\left(\begin{array}{cccc|c}1&2&3&-4&5\\1&3&3&3&3\\0&-1&0&-7&2\end{array}\right) \xrightarrow{\ R_{1,2}(-1)\ } \left(\begin{array}{cccc|c}1&2&3&-4&5\\0&1&0&7&-2\\0&-1&0&-7&2\end{array}\right)\\[8pt] &\xrightarrow{\ R_{2,3}(1)\ } \left(\begin{array}{cccc|c}1&2&3&-4&5\\0&1&0&7&-2\\0&0&0&0&0\end{array}\right) \xrightarrow{\ R_{2,1}(-2)\ } \left(\begin{array}{cccc|c}1&0&3&-18&9\\0&1&0&7&-2\\0&0&0&0&0\end{array}\right) \end{aligned}$$

마지막 행렬에서 선도원소는 $1$열과 $2$열에 있으므로 $p,q$ 가 선도변수이고 $r,s$ 는 자유변수이다. 자유변수 $r$ 과 $s$ 를 각각 $r=u$, $s=w$ 로 두고 두 행을 각각 선도변수에 대해 풀면 다음과 같다.

$$\begin{cases}p\ \ \ \ \ +3r-18s=\ \ \ 9\\ \ \ \ \ q\ \ \ \ \ \ \ +7s=-2\end{cases} \ \longrightarrow\ \begin{cases}p=-3u+18w+9\\ q=\ \ \ \ \ \ \ -7w-2\end{cases}$$

따라서 해는 다음과 같이 무수히 많다.

$$p=-3u+18w+9,\quad q=-7w-2,\quad r=u,\quad s=w$$

예를 들어 $u=1$, $w=0$ 으로 두면 $p=6$, $q=-2$, $r=1$, $s=0$ 이 해가 되고, $u=0$, $w=0$ 으로 두면 $p=9$, $q=-2$, $r=0$, $s=0$ 이 또 다른 해가 된다.

세 번째 행이 영행이 된 것에 주목하자. 원래 세 번째 방정식이 앞의 두 방정식으로부터 얻어지는 중복된 정보였다는 뜻이다. 방정식이 $3$ 개, 미지수가 $4$ 개였지만 실제로 쓸모 있는 방정식은 $2$ 개뿐이었고, 그래서 자유변수가 $4-2=2$ 개 생겨 매개변수 $u,w$ 두 개짜리 해집합이 나왔다.
