연습문제2장 exercises

2장 본문의 예제와 교재 연습문제를 모은 것이다. 풀이는 본문 노트와 증명·정리 퀴즈 참고.

예제 examples

예 2.6결합밀도 $f_{X,Y}(x,y)=xy\,e^{-(x+y)}\ (x,y\gt0)$ 에 대하여 $P(X\ge2Y)$ 를 구하라.
예 2.8확률밀도함수 $f_{X,Y}(x,y)=8xy\ (0\lt x\lt y\lt1)$ 에 대하여 결합분포함수 $F_{X,Y}(x,y)$ 를 모든 $(x,y)$ 에서 구하라.
예 2.9세 범주의 확률이 $\tfrac16,\tfrac26,\tfrac36$ 인 시행을 $n$ 번 반복한 횟수 $(X_1,X_2,X_3)$ 의 결합 pmf 가 $f(x_1,x_2,x_3)=\dfrac{n!}{x_1!\,x_2!\,x_3!}\big(\tfrac16\big)^{x_1}\big(\tfrac26\big)^{x_2}\big(\tfrac36\big)^{x_3}$ ($x_1+x_2+x_3=n$) 일 때, $X_1$ 의 주변 확률질량함수 $f_{X_1}(x_1)$ 를 구하라.
예 2.10결합밀도 $f_{X,Y}(x,y)=xy\,e^{-(x+y)}\ (x,y\gt0)$ 에서 주변밀도 $f_X(x)$ 와 $f_Y(y)$ 를 구하라.
예 2.12결합밀도 $f_{X,Y}(x,y)=x^2e^{-x(y+1)}\ (x,y\gt0)$ 에서 조건부밀도 $f_{Y\mid X}(y\mid x)$ 를 구하고, $X=x$ 가 주어졌을 때 $Y$ 가 어떤 분포를 따르는지 밝혀라.
예 2.13결합 pmf $f_{X,Y}(x,y)=\dfrac{2^{x+y}e^{-4}}{x!\,y!}\ (x,y=0,1,2,\dots)$ 에서 $X,Y$ 가 독립인지 판정하라.
예 2.31다항분포 $(X_1,X_2,X_3)\sim\text{MULT}(n,p_1,p_2,p_3)$ 에서 서로 다른 두 범주의 횟수는 음의 공분산을 가짐, 즉 $Cov(X_1,X_2)=-np_1p_2\ (\lt0)$ 임을 보여라.
예 2.35$7$ 전 $4$ 선승 시리즈에서 매 경기 승률이 $p=0.7$ 일 때, 정확히 $5$ 경기 만에 우승할 확률 $P(X=5)$ 를 음이항분포로 구하라 ($r=4$).
예 2.36$100$ 개들이 상자에 불량품이 $30$ 개 있고, 이 중 $10$ 개를 비복원 랜덤추출한다. 불량품 개수 $X$ 의 $P(X\le2)$ 를
  1. 초기하분포 $\text{HYP}(10,100,30)$ 으로 구하고,
  2. $p=30/100=0.3$ 인 이항분포로 근사해 구한 뒤, 두 값을 비교하라.
예 2.38$X\sim N(25,16)$ 일 때 $P(20\le X\le35)$ 를 표준화하여 $\Phi$ 로 나타내고 값을 구하라.
예 2.40확률변수 $X$ 의 밀도 $f_X$ 를 알 때 $Y=X^2$ 의 밀도 $f_Y(y)$ 를 구하라. 특히 $X\sim N(0,1)$ 이면 $Y$ 가 어떤 분포인지 밝혀라.
예 2.42독립 $X,Y\sim U(0,1)$ 의 합 $Z=X+Y$ 의 밀도 $f_Z(z)$ 를 합성곱으로 구하라.
예 2.44독립 베르누이 $X_1,X_2,X_3$ 에서 $Y_1=X_1+X_2+X_3$, $Y_2=|X_3-X_2|$ 의 결합 pmf 를 표로 구하라.
예 2.45독립 $X_1,X_2\sim\text{EXP}(1)$ 에서 $Y_1=X_1+X_2$, $Y_2=X_1-X_2$ 라 하자.
  1. 야코비안으로 $(Y_1,Y_2)$ 의 결합밀도와 그 지지집합을 구하라.
  2. $Y_1,Y_2$ 의 주변분포를 각각 구하고 어떤 분포인지 밝혀라.
  3. $Y_1,Y_2$ 가 독립인지 판정하라.
예 2.46독립 $X_1,X_2\sim N(0,1)$ 에서 비 $Y=X_1/X_2$ 의 분포를 구하라.
예 2.52이항분포 $B(n,p)$ 의 적률생성함수 $M(t)=(q+pe^t)^n$ 을 이용해 평균과 분산을 구하라.
예 2.56–2.59적률생성함수와 유일성으로 다음 독립합의 분포를 각각 구하라.
  1. 독립 $\text{Ber}(p)$ $n$ 개의 합
  2. 독립 $\text{POI}(\lambda_i)$ 들의 합
  3. 독립 $\text{EXP}(\theta)$ $n$ 개의 합
  4. 독립 정규합 $\sum a_iX_i$ (단 $X_i\sim N(\mu_i,\sigma_i^2)$)
예 2.61이항 $B(n,p)$ 와 포아송 $\text{POI}(\lambda)$ 의 확률생성함수 $G_X(s)$ 를 각각 구하고, $G_X'(1)$ 로 평균을 확인하라.

연습문제 exercises

04$n$ 개의 함수 $f_i(x)\ (i=1,2,\cdots,n)$ 들이 각각 확률밀도함수의 조건들을 만족하면, $p_i\gt0$, $\displaystyle\sum_{i=1}^n p_i=1$ 에 대하여 $\displaystyle\sum_{i=1}^n p_if_i$ 도 확률밀도함수의 조건들을 만족함을 보여라.
06확률변수 $X$ 의 누적분포함수가 $$F_X(x)=\begin{cases}0,& x\lt0\\ 1-(1/2)^{x+1},& x=0,1,2,\cdots\end{cases}$$ 으로 주어졌다. 이때
  1. 확률변수 $X$ 의 확률밀도함수를 구하라.
  2. $X$ 가 짝수값을 가질 확률을 구하라.
  3. $P(10\lt X\lt20)$ 을 구하라.
08이변량 확률벡터 $(X,Y)$ 의 결합 누적분포함수가 $F(x,y)$ 라고 할 때 $$P(a\lt X\le b,\ c\lt Y\le d)=F(b,d)-F(b,c)-F(a,d)+F(a,c)$$ 이 성립함을 보여라.
10동전을 $3$ 회 던졌을 때 $X=$ 앞면이 나오는 횟수, $Y=$ 뒷면이 나오는 횟수라고 하자.
  1. $X,Y$ 의 결합 확률밀도함수를 구하라.
  2. $X,Y$ 의 주변 확률밀도함수를 구하라.
  3. 조건부 확률밀도함수 $f_{Y\mid x}(y\mid x)$ 를 구하라.
12두 확률변수 $X$ 와 $Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=\begin{cases}2e^{-x}e^{-2y},& 0\lt x\lt\infty,\ 0\lt y\lt\infty\\ 0,& \text{그 외의 경우}\end{cases}$$ 라고 하자. 이때
  1. $P(X\gt1,\ Y\lt1)$ 을 구하라.
  2. $P(X\lt Y)$ 를 구하라.
  3. 양의 상수 $a$ 에 대하여 $P(X\gt a)$ 을 구하라.
16두 확률변수 $X,Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=2,\qquad 0\lt x\lt1,\ 0\lt y\lt1-x$$ 일 때,
  1. 조건부 확률밀도함수 $f_{Y\mid x}(y\mid x)$ 를 구하라.
  2. $P(0\lt Y\lt3/4\mid X\lt1/2)$ 을 구하라.
18확률변수 $X$ 의 확률밀도함수가 $f_X(x)=1,\ 0\lt x\lt1$ 일 때, $Y=3X+1$ 의 확률밀도함수를 구하라.
20확률변수 $X$ 의 확률밀도함수가 $f_X(x)=3e^{-3x},\ x\gt0$ 일 때
  1. $Y=2X+5$ 의 확률밀도함수와 확률분포함수를 구하라.
  2. $Y=\dfrac1X$ 의 확률밀도함수와 확률분포함수를 구하라.
22$X\sim N(0,1)$ 일 때, $Y=X^2$ 의 확률밀도함수를 누적분포함수를 이용한 방법으로 구하라.
23연속형 확률변수 $X$ 의 누적분포함수를 $F(x)$ 라고 하면, $U=F(X)$ 는 구간 $(0,1)$ 상에서 균일분포를 가짐을 보여라.
24두 확률변수 $X,Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=2(x+y),\qquad 0\le x\le y\le1$$ 일 때, $Z=X+Y$ 의 확률밀도함수를 구하라.
27이산형 확률변수 $X$ 의 확률밀도가 $$f(x)=\begin{cases}2^{-x},& x=1,2,\cdots\\ 0,& \text{그 외의 경우}\end{cases}$$ 으로 주어졌을 때, $2^X$ 의 기댓값이 존재하지 않음을 보여라 (참조: 정의 2.7).
